新增精舍

只需輸入精舍代碼，系統會自動給予統一預設密碼「1234」，6 種試算表 ID 留空由精舍自行登入設定。 Email 為選填欄位，用於登記精舍聯絡人／接手人身份，僅作記錄用途，不影響精舍登入方式（精舍登入仍為精舍代碼＋密碼）。

修改精舍設定（救援用）

選擇精舍代碼後按「載入」，會帶出目前設定；Email／3 種試算表相關 ID 欄位（資料庫試算表ID、 學員基本資料試算表ID、精舍資料夾ID）會直接顯示目前已存的實際內容，可直接修改覆蓋，若不想變更 請保持原樣即可。密碼欄位基於安全考量固定留空，不顯示明碼，需要重設密碼時才手動輸入新密碼； 欲查看目前密碼明碼請至上方「精舍清單」表格點擊「顯示」。提報名單／出席回報／報到名單／封存 備查等 4 個試算表 ID 屬於當年度一次性資料，由系統自動建立與管理，不在本卡片提供修改。 此功能供精舍忘記密碼、長期固定試算表 ID 設定錯誤等狀況時，由總管理員協助修正。

刪除精舍

刪除僅移除該精舍的「登入帳號、密碼、試算表 ID 等設定資料」，不會刪除該精舍名下實際的 Google 試算表檔案（試算表本身仍完整保留在雲端硬碟中）。此操作為硬刪除，執行後無法從本頁復原， 請務必先載入資料摘要確認無誤，並輸入精舍代碼進行二次確認後才會執行。
