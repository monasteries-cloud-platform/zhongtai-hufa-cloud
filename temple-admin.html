精舍後台管理　

報到場次管理 → 提報名單資料組操作 →

修改精舍密碼

新精舍預設密碼為 1234，是否修改由貴精舍自行決定，不強制。若不修改，可以繼續使用預設密碼。

自動建立試算表

填入貴精舍未來要用來管理試算表的 Google 帳號 Email，按下方按鈕後，系統會自動建立 貴精舍專屬的 Drive 資料夾（若尚未建立過），並在裡面複製 2 份最新範本（資料庫、學員 基本資料），建立成貴精舍專屬的正式試算表，自動把試算表 ID 與資料夾 ID 填入下方 「試算表 ID 設定」。提報名單／出席回報／報到名單這 3 種試算表不需要在這裡建立， 系統會在貴精舍第一次實際使用對應功能時自動建立。建立後會嘗試把試算表與資料夾的 擁有權轉移給您填的 Email；若您的帳號跟中台帳號不同網域（例如一般個人 Gmail），該 信箱會收到 Google 的「轉移檔案擁有權」通知信，需要您登入該帳號點擊接受才會完成 正式轉移，接受前試算表與資料夾仍可正常使用。

試算表 ID 設定

一般情況下建議使用上方「自動建立試算表」即可，不需要手動填寫這裡。這裡保留作為手動 救援或個別微調用途：可直接貼上既有 Google 試算表 ID（試算表網址中 /d/ 與 /edit 之間 的一長串英數字）或資料夾 ID（資料夾網址 /folders/ 後面的一長串英數字）。未填寫的欄位 會維持原本設定不變。提報名單／出席回報／報到名單這 3 種「當年度一次性」試算表不在 這裡設定，由系統自動建立，若真的需要手動介入，請聯絡總管理員到「系統管理」處理。

封存並開始下一期

每年提報作業全部完成後執行本功能：會把本期的提報名單、審核流程資料（候選清單／待 複核清單／核定名單）、出席調查表、已輸出到報到系統的報到資料，整批封存成一份獨立的 「封存備查」試算表（存放在貴精舍專屬 Drive 資料夾的「封存檔案」子資料夾內，不會 刪除任何原始資料），並把本期核定名單複製成下一期提報作業的起始名單。執行完成後， 提報名單／出席回報／報到名單這 3 份試算表會全部重置，下次貴精舍實際使用對應功能 時，系統會自動建立全新的空白試算表；「本期組別啟用設定」「組長名冊」不受影響， 沿用到下一期。此操作無法復原，執行前請確認本期作業真的已經全部 完成、不會再有異動。
歷年封存查詢：選擇下方年度／封存時間，會開新分頁直接開啟該次封存的試算表。
